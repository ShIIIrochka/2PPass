# Структура проекта 2PPass

## Общая структура

```
src/
├── config/              # Конфигурация Django проекта
│   ├── settings.py      # Настройки приложения
│   ├── urls.py          # Главный URL конфиг
│   ├── mongodb.py       # Подключение к MongoDB
│   ├── wsgi.py          # WSGI конфигурация
│   └── asgi.py          # ASGI конфигурация
│
├── apps/                # Приложения Django
│   ├── users/           # Управление пользователями
│   ├── vaults/          # Управление хранилищами
│   ├── passwords/       # Управление паролями
│   ├── audit/           # Журнал аудита
│   └── roles/           # Роли и права доступа
│
└── manage.py            # Django management script
```

## Структура приложения

Каждое приложение имеет следующую структуру:

```
app_name/
├── models.py            # Модели данных (Django ORM + MongoEngine)
├── views.py             # Представления (DRF ViewSets)
├── serializers/         # Сериализаторы DRF
├── urls.py              # URL маршруты приложения
├── permissions/         # Кастомные права доступа
├── utils/               # Утилиты приложения
├── constants.py         # Константы
├── admin.py             # Админ-панель
└── tests.py             # Тесты
```

## Приложения

### apps.users
Управление пользователями, аутентификация, профили.

### apps.vaults
Управление хранилищами паролей, группами, доступом.

### apps.passwords
Управление паролями, версионность, корзина, генерация.

### apps.audit
Журнал действий пользователей, логирование операций.

### apps.roles
Кастомные роли и права доступа.

## Базы данных

- **SQLite** (Django ORM): для пользователей, сессий, админки
- **MongoDB** (MongoEngine): для паролей, хранилищ, аудита

## API Endpoints

- `/api/users/` - управление пользователями
- `/api/vaults/` - управление хранилищами
- `/api/passwords/` - управление паролями
- `/api/audit/` - журнал аудита
- `/api/roles/` - роли и права
